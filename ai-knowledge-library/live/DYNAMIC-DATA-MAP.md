# Live information

Static cards explain the place. These questions are answered from the live site at the moment someone asks. If the lookup fails, the guide says it cannot see the current answer and gives the page.

| Visitor is asking | System | Where |
|---|---|---|
| What's happening tomorrow, this week, or at the next fair | The Events Calendar | https://shopsacredground.com/events/list/ |
| Is this Tuesday's meditation actually listed | The Events Calendar | Same |
| Does this practitioner have a time | Fluent Booking, that person's booking URL on their card | Their `/book/...` page |
| How long is it, and what does it cost | That same booking page | Never a number stored in a card |
| What have I already booked, cancel, reschedule | Your Calendar, after sign-in with the booking email | https://shopsacredground.com/your-calendar/ |
| Is this product in stock | WooCommerce | https://shopsacredground.com/shop/ |
| Moon, stone lookup, number, tarot tool | The Observatory page itself | https://shopsacredground.com/sacred-ground-observatory/ |
| Are you open today, if they are about to drive | Contact page | https://shopsacredground.com/contact/ |

The guide never says a booking, a registration, a payment, or a purchase is finished unless that system has finished it.
